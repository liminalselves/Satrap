# 插件管理页

管理面板侧栏的「插件管理」汇总内置目录 `satrap/expend/plugins` 与用户目录 `.satrap/plugins` 中的插件。支持按名称、作者或说明搜索, 按来源和适用平台筛选, 点击插件进入详情

概览展示版本、作者、兼容版本、适用环境和五类能力声明。声明来自 `meta.yaml`, 不代表每个运行实例已经加载成功。使用位置数量包含已添加的 Chat 及所有引用该插件的 Edictum 命名配置, 已添加但停用的位置仍计入, 同一命名配置只计一次

## 从 ZIP 安装

点击「安装插件」, 选择或拖入 ZIP, 校验成功后查看预览, 再点击「安装」。也可以取消预览, 临时文件随即清理。预览有效期为十分钟

支持两种压缩包结构:

```text
meta.yaml
tools.py
```

或:

```text
package/
  meta.yaml
  tools.py
```

每个 ZIP 只能包含一个插件。插件名称取自 `meta.yaml` 的 `name`, 限制为 1 到 64 位英文字母、数字、下划线、点或连字符, 且必须是合法的目录名。安装位置为 `.satrap/plugins/<name>`

上传最大 20 MiB, 解压后最大 100 MiB, 最多 2000 个条目, `meta.yaml` 最大 1 MiB。不支持加密 ZIP, 拒绝链接、越界路径、Windows 保留名称及大小写冲突的路径

校验和预览只读取元数据, 不执行插件代码。安装采用同一文件系统内的目录移动, 完成后打开新插件详情。安装不会自动启用插件, 也不修改 Chat 或 Edictum 的插件配置

遇到同名内置或用户插件时拒绝安装。第一版不支持覆盖更新、卸载及在线市场

## 全局参数

详情页的「全局参数」根据插件声明生成表单, 支持模型和知识库选择。全局参数供各使用位置继承, 命名配置和会话自定义字段优先于全局值

修改保留为草稿, 点击「保存全局参数」后写入。刷新插件概览不会覆盖表单, 保存失败保留草稿, 离开页面或切换标签时提示未保存修改。「恢复默认值」清除全局显式字段, 点击保存后生效

保存后分别协调 Chat 与后端 Edictum 的插件实例, 页面区分配置保存和运行应用结果。应用失败不会撤销已保存的参数, 可点击「重试运行应用」重新协调。服务停止或尚无活动实例时显示「下次激活时应用」; 请求超时显示失败, 不视为服务停止

多个页面同时编辑时, 旧版本保存返回冲突, 需要重新读取后合并修改

## 使用位置与运行实例

「使用位置」列出 Chat 与所有 Edictum 命名配置。选择位置后可以添加插件、修改聚合启用状态、分别开关工具、技能、MCP、前处理和命令, 或移除该位置的插件引用。修改采用草稿, 点击「保存使用配置」后生效

停用插件保留子能力的独立状态, 再启用时按原状态恢复。移除只删除所选位置的插件配置, 不删除安装目录。命名配置中已设置的参数覆盖及其他插件不会被能力开关操作改写。保存使用配置后也会协调运行实例, 应用失败时可重试

运行实例区域每五秒只读刷新, 不触发安装或模型请求, 也不改变配置草稿。展示各实例的加载状态、错误、漂移和实际扫描到的能力。未声明但实际加载的能力也会出现在运行明细中; 自定义插件句柄未提供明细时显示「未提供加载明细」, 不推测其能力为空

点击「配置此会话参数」打开已有会话覆盖表单。点击「打开命名配置参数」跳转并打开对应 Edictum 插件配置, 未覆盖的字段显示继承的全局值, 支持恢复继承。仅会话覆盖受 `session_overridable` 限制, 命名配置仍可配置相应字段

Chat 与 Edictum 原有快捷入口保留, 共享能力显示组件, 并可在新标签页打开插件详情。Chat 的全局参数弹窗使用同一全局配置保存接口, 同时协调 Chat 与 Edictum
