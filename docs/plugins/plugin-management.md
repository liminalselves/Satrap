# 插件管理页

管理面板侧栏的「插件管理」汇总内置目录 `satrap/expend/plugins` 与用户目录 `.satrap/plugins` 中的插件。支持按名称、作者或说明搜索, 按来源和适用平台筛选, 点击插件进入详情

概览展示版本、作者、兼容版本、适用环境和五类能力声明。声明来自 `meta.yaml`, 不代表每个运行实例已经加载成功。使用位置数量包含已启用的 Chat 及所有引用该插件的 Edictum 命名配置, 同一命名配置只计一次

## 从 ZIP 安装

点击「安装插件」, 选择或拖入 ZIP, 校验成功后查看预览, 再点击「安装」。也可以取消预览, 临时文件随即清理。预览有效期为十分钟

支持两种压缩包结构:

```text
meta.yaml
tools.py
```

或:

```text
package/
  meta.yaml
  tools.py
```

每个 ZIP 只能包含一个插件。插件名称取自 `meta.yaml` 的 `name`, 限制为 1 到 64 位英文字母、数字、下划线、点或连字符, 且必须是合法的目录名。安装位置为 `.satrap/plugins/<name>`

上传最大 20 MiB, 解压后最大 100 MiB, 最多 2000 个条目, `meta.yaml` 最大 1 MiB。不支持加密 ZIP, 拒绝链接、越界路径、Windows 保留名称及大小写冲突的路径

校验和预览只读取元数据, 不执行插件代码。安装采用同一文件系统内的目录移动, 完成后打开新插件详情。安装不会自动启用插件, 也不修改 Chat 或 Edictum 的插件配置

遇到同名内置或用户插件时拒绝安装。第一版不支持覆盖更新、卸载及在线市场
