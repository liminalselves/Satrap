# 使用指南

这份说明介绍 Satrap 管理面板的结构和常用操作。它随当前版本一起发布, 内容与你正在使用的界面一致。

## 面板结构

左侧导航按领域分组:

| 分组 | 页面 | 用途 |
| --- | --- | --- |
| 概览 | 仪表盘 | 服务状态、今日消息与 Token、最近动态 |
| 智能 | 模型配置、知识库 | 添加模型与 API Key, 管理 RAG 知识库 |
| 编排 | Agent 配置、插件管理 | 定义 Agent 会话类, 启用插件与能力 |
| 平台 | 平台状态、审批 | 接入 QQ / OneBot、Misskey, 处理待审批动作 |
| 数据 | 对话记录、会话实例、用量统计 | 查看历史、实例与模型用量 |
| 运维 | 日志监控、调试日志、系统设置 | 排查问题与调整系统配置 |

按 `Ctrl` + `K` 打开命令面板, 可以直接搜索页面或执行启动、停止后端等操作。右上角可切换深浅主题。

## 第一次使用

1. 启动服务后打开管理面板, 默认地址为 `http://127.0.0.1:19871`。
2. 在 **模型配置** 添加模型: 填写名称、API 地址和 API Key。
3. 打开 **Chat** 页面, 点输入框旁的 **展开选项** 选择模型, 即可开始对话。
4. 需要接入聊天平台时, 在 **平台状态** 新建平台并绑定 Agent, 按提示应用配置或重启后端。OneBot 协议端需要单独部署。

如果启用了访问密码, 打开面板时会先要求登录。密码在 **系统设置 → 访问密码** 中设置和清除。

## Chat 对话

- 进入 Chat 默认是新对话, 直接输入即可。历史会话在左侧列表中, 点击即可继续。
- 对话可以归入项目, 项目会绑定一个工作区目录, 供文件类工具使用。
- 输入框旁的 **展开选项** 可快速切换模型、思考强度和审批模式; 右上角 **对话设置** 中还可以设置系统提示词、整体默认模型, 以及管理插件和数据。
- **执行审批模式** 决定模型调用工具前是否需要你确认: 请求批准、帮我审批或完全访问。

## 平台与 Agent

- **Agent 配置** 定义机器人在不同场景下使用的会话类和插件。
- **平台状态** 显示每个适配器的连接情况和最近 14 分钟的消息量。启停平台后, 状态标签会说明配置是否已在运行时生效。
- 群聊相关的唤醒方式、频率与时段规则, 在平台的编辑窗口中设置, 并可以用 **试算** 预览某条消息是否会触发回复。

## 插件

**插件管理** 列出所有内置和用户插件。每张卡片底部的状态含义:

| 状态 | 含义 |
| --- | --- |
| 运行正常 | 期望的运行服务都可用, 观测到的实例正常 |
| 部分异常 | 至少一个运行实例报错或需要重启 |
| 执行已关闭 | 插件的执行总闸已关闭 |
| 已停用 / 未被使用 | 所有实例中都停用, 或没有任何位置引用它 |
| 服务离线 | Chat 服务或平台后端暂不可用, 无法确认状态 |
| 未加载 | 服务可用, 但还没有加载过使用该插件的会话 |

鼠标停在状态上可以看到完整原因。

## 审批

模型或插件发起的群管理、好友申请、入群邀请和记忆提案, 会进入 **平台 → 审批**。可以单条或批量批准、拒绝, 刚做出的决定可以短时间内撤销。

## 数据与日志

- **对话记录** 按对话或按用户查看模型上下文和展示历史。
- **会话实例** 显示每个平台会话实例所属的群或私聊, 以及近 14 日 Token 用量。
- **用量统计** 按时间、模型和会话实例拆分模型调用次数、Token 和耗时。未返回用量的调用仍计入次数, Token 显示为未知。
- **日志监控** 查看实时服务日志; **调试日志** 按会话查看一次请求经过的各个阶段。

## 系统设置

| 分节 | 内容 |
| --- | --- |
| 外观 | 主题、动效与侧栏 |
| 常用配置 | 监听地址、会话与限流 |
| 后端控制 | 启动、重启平台后端 |
| 访问密码 | 启用、修改或清除面板密码 |
| 管理员 | 管理组、例外与权限 |
| 日志保留 | 日志保留策略与清理 |
| 数据维护 | 孤儿数据与回收区 |
| 原始配置 | 直接编辑 YAML 配置, 保存前会校验 |
| 关于 | 版本、服务运行环境, 以及本文档入口 |

## 常见问题

**面板显示服务离线**
确认启动窗口仍在运行。控制服务和聊天服务的启动诊断日志在 `.satrap/release-logs/`。

**端口被占用**
默认使用 `19870`、`19871`、`19872` 三个端口。停止占用端口的程序, 或改用其他端口启动, 所有端口必须互不相同。

**没有可选的模型**
先在 **模型配置** 添加模型并填写有效的 API Key, 再回到 Chat 选择。

**插件显示服务离线或未加载**
这表示暂时看不到它的运行状态, 不代表插件被关闭。启动平台后端, 或打开一个使用该插件的会话后再刷新。
