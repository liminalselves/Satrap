# 前端加载与记住登录实施结果

日期: 2026-10-23

基线提交: `b295cc24e2f393f897880399e99a53818cc2ff91`, 分支: `fix/issue-24`; after 来自当前工作区, 构建摘要和源码差异摘要见原始 JSON

## 已完成的改动

- 仪表盘改读一次轻量概览, 不为计数下载所有模型配置; 模型与插件读取正文和版本信封, 共享在途版本探测, 保留来源变更检查和取消语义
- Chat 初始化独立加载必要数据, 同一模型详情不再重复请求; 会话列表和历史各按 50 条分页, 使用稳定游标, 回答变体按需读取
- Chat 目录和历史 HTTP 查询放进有界线程池; 全量目录遍历不再循环重复聚合, 分页计数使用同一次聚合, 标题延后到当前页读取
- 管理端目录用 SQL 摘要替代读取每轮完整输入, 多平台并发上限为 4, 精确 ID 读取减少无关资料构造
- 登录页默认勾选“记住此浏览器 (30 天)”, 随机 Cookie 的摘要持久保存在独立的 `credentials/browser-sessions.db`, 不保存明文密码或原始 Cookie
- 已有 Cookie 可以恢复 `/auth/session`, 浏览器及服务重启后可继续使用; 同部署范围内可由有效的同站服务凭据为后来启动的服务恢复登录, 普通 API 仍只认自身服务的 Cookie
- 只在恢复时按天续期, 普通 API 核验只读; 页面每 6 小时安静检查一次已登录服务, 退出登录或修改密码后旧凭据失效

HTTPS 使用 Secure, Cookie 保留 HttpOnly / SameSite=Strict / host-only; 不扩大现有 Origin 白名单, 不提供跨域名同步登录

## 基准方法

- Windows win32 10.0.26200, Node v24.18.0, Chromium 151.0.7922.34, Python 3.13; 前后使用同一浏览器版本和合成数据
- 浏览器使用 Vite 生产构建, 每场景 2 次预热和 10 次正式采样, 从导航到对应数据实际可见; 0 / 150 / 300ms 是每次 API 的额外模拟等待, 不是实际公网 RTT
- 最终主加载 after 单独串行运行, 没有并行构建或回归任务; 中间复测出现的低延迟回退没有在最终隔离复测中复现
- 查询微基准使用内存 SQLite 与生产函数, 每组 2 次预热和 30 次正式采样; 并发路由使用临时磁盘 SQLite, 2 次预热和 10 次正式采样
- 页面性能由合成 HTTP / WS 夹具测量, 不是实际三服务部署的端到端延迟; 真实 HTTP 和浏览器关闭重开由认证回归测试验证
- 所有基准均不读取远端或用户会话数据库; 临时环境放系统临时目录, `.toolkit` 没有新增实验文件

## 记住登录验证

- 旧逻辑即使 Cookie 有效, 再调用 `/auth/session` 仍返回 401; 新逻辑在新 ServerAuth 实例中可返回 200
- 100 次恢复采样: P50 2.02ms, P95 3.03ms; 当日重签 Cookie 0 次, 数据库 mtime 和大小均未变化
- 旧逻辑和新逻辑的认证路径语义不同, 不把这组函数耗时计算成认证性能改善比例
- 真实 HTTP 回归覆盖记住 / 不记住, 服务重建, 续期, 服务命名空间, 跨部署拒绝, 改密失效与退出撤销
- Windows 实际关闭并重开 Chromium 进程, 同时重建服务对象, 不提交密码即可恢复; Linux 相应浏览器依赖未安装, 此项跳过
- 更新前的短期 Cookie 不会自动变成持久登录; 更新后首次密码登录勾选记住, 此后有效期内无需再次输入, 退出或清除浏览器 Cookie 后需重新登录

## 未达目标与边界

- 5,000 会话首屏 SQL 查询改善约 48%, 未达到计划的 70%; 全量遍历和浏览器首屏已显著改善, 后续若继续降低该查询需评估统计索引或统计表
- 模型热缓存 P50 477.0→486.5ms, 约回退 2.0%, 请求从 4 次降到 1 次; 模型 / 插件热缓存 P95 分别约回退 1.0% / 3.1%, 不宣称所有缓存场景都变快
- 100 轮滚动平均 FPS 下降约 10%, 帧 P95 基本不变; 未隐藏此项回退, 更长历史及流式场景没有同方向回退
- 通用管理目录的复杂适配器归属和筛选仍保留元数据读取后的 Python 筛选, 没有把所有分类分页下推成 SQL
- WS 恢复快照保持原有序列语义, 最新 50 轮仍在事件循环中同步捕获; 本轮减少数据量, 不声称已经消除所有 SQLite 同步路径
- 本轮没有远端生产部署抽样, 也未把浏览器夹具与后端微基准拼成真实公网端到端延迟
