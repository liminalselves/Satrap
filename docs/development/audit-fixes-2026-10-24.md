## 范围与兼容性

- 第 5 项复用标准回收流程, 失败的新会话退出活跃配置和实例池; 有实际数据时保留可恢复的回收记录, 不进行不可恢复删除
- 第 6 项只信任显式旧用户绑定并核验配置存在性、Provider 与类型, 不从 scope_ 或会话 ID 推断归属
- 第 21 项不再承诺每次本地读取检测同大小磁盘改写. 路径、普通文件和大小校验继续保留; 冻结复制仍计算摘要, OneBot 仍核验远端组装结果, 分支复制在写入时核验摘要
- 第 24 项不影响未启用 UserManager 的本地 CLI 会话; 独立宿主使用 UserManager 时需显式传入 ConversationRoute
- 第 25 项要求前后端使用相同发布版本. 未提供 snapshotLoader 的普通版本化读取仍保留自己的读取协议, 移除的是端点缺失时的隐式降级
- 审计外回归: 全量测试发现离线群管理 API 与 SPA 页面路径冲突. Control 群接口和对应前端请求已统一为 /api/platforms/...; /platforms/... 继续作为页面, 新 API 的读写均经过鉴权
