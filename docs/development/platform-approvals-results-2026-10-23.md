# 对话记录与统一审批中心验收

日期: 2026-10-23

本轮已完成本地修改与验收, 未连接或部署远端服务器

## 实现范围

- 对话记录以服务端 supports_history 能力决定显示方式: 平台对话只显示“模型上下文”标题和平台消息档案链接; 支持 Chat 历史的对话保留可切换标签, 包括空历史, 键盘导航和未保存编辑保护
- 平台状态新增审批中心, 聚合群管理, 机器人入群邀请和好友动作; 默认待人工批准, URL 保留平台, 账号, 来源, 目标, 状态, 动作 ID 和游标
- 群和好友动作页保留历史, 将审批按钮收拢为中心链接; 邀请弹窗仍处理原始邀请, 提交后等待审批的动作转到中心
- 汇总仅只读访问已存在的两个动作表, 不实例化会触发恢复的业务存储, 不建库, 不迁移, 不修改过期记录; 邀请不重复归类, 跨表同名 ID 以完整身份区分
- 人工决策分派到原有三个业务接口, 原权限, 保护规则和原子占用不变; 响应丢失后读取原动作, 不重放写请求; 未确认结果无重试执行按钮
- 当前账号与查询指定账号独立传递, 多平台使用各自当前身份; 历史账号, 离线平台和到期动作禁用决策
- 有界工作线程最多并发读取 4 个平台, 默认每页 50 条, 最大 100; 每个平台一页与计数同快照, 跨平台不保证全局原子快照
- 前台普通轮询 10 秒, 执行中前 60 秒为 2 秒, 隐藏页面停止; 平台列表仅读取摘要, 不逐群查询

## 查询规模基准

Windows 本机 Python 3.13, 临时合成 SQLite 数据库, 每组 2 次预热和 30 次正式采样; 测量当前生产读取函数及健康检查路由, 不包含 HTTP 传输, 公网和真实平台 API 耗时

列表每次读取首批 50 条, 摘要只计数; SQL 次数含事务与元数据语句, 是整个请求的总量, 不随群数增长

## 交付边界

本轮没有新增自动审批策略或统一写入接口, 原始申请不混入待批准动作; 各平台策略继承关系保持原业务定义

部分平台失败会展示覆盖警告和已读取结果, 数量是已确认范围的下限; 当前身份未确认时不会显示为已确认的零条

中心中可见不保证仍能执行, 最终由原决策接口复核; 不提供批量批准或 unknown 自动重试
