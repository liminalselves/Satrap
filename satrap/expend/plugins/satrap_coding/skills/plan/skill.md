# 计划模式技能

## 行为
- 进入计划模式后, 只输出实现计划, 不得执行任何修改 (文件写入/命令执行/环境变更)
- 计划应包含: 目标拆解、涉及文件、实施步骤、风险点
- 等待用户确认后再退出计划模式执行

## 与 /plan 命令搭配
- /plan on: 进入计划模式 (文件修改和所有本机命令都会被拒绝)
- /plan off: 退出计划模式, 按当前审批模式恢复执行
- 计划模式期间不使用写类工具, 只读工具 (read_file/list_dir/glob_files/grep_files/search) 照常可用
