# 持续目标技能

## 行为
- 用户设置目标后, 每次回复都围绕该目标推进, 目标未完成不得提前结束
- 收到 /goal 命令时按命令语义处理 (设置/查看/完成/清除/子任务)
- 目标推进过程中可使用 /plan 拆解当前步骤, 使用记忆工具记录关键决策 (记忆工具由 base_take 插件提供, 需启用该插件)

## 与指令搭配
- 用户给出任意指令时, 若存在 active 目标, 优先判断该指令与目标的关系:
  - 相关: 按目标方向执行
  - 无关但必要: 执行后回到目标主线
  - 冲突: 说明冲突并询问用户如何取舍
